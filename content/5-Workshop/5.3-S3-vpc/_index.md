### Detailed Implementation Steps

### Step 1: Virtual Private Cloud and Routing Setup (Amazon VPC)

The first step is to establish the network infrastructure that separates public-facing resources from private resources to enhance system security.

- Create a custom **Amazon VPC** named **Tracker-VPC** in the **ap-southeast-2 (Sydney)** Region using the IPv4 CIDR block **10.0.0.0/16**.
- Divide the VPC into two subnets:
  - **Public Subnet:** Hosts the Spring Boot application running on Amazon EC2 and accepts incoming Internet traffic.
  - **Private Subnet:** Hosts the Amazon RDS database and prevents direct access from the Internet.
- Create and attach an **Internet Gateway (IGW)** to the VPC.
- Configure the **Route Table** of the Public Subnet to forward Internet traffic (`0.0.0.0/0`) through the Internet Gateway.

### Step 2: Secure Database Deployment (Amazon RDS)

Deploy an **Amazon RDS PostgreSQL** database instance inside the Private Subnet to securely store application data.

Configure the database **Security Group** to:

- Deny all direct public Internet access.
- Allow inbound connections only from the Security Group attached to the EC2 application server.

### Step 3: Application Server Deployment and IAM Configuration (Amazon EC2 & IAM)

Before deploying the application, configure an **IAM Role** following the **Principle of Least Privilege**. The role grants the EC2 instance permission to access Amazon S3 and Amazon CloudWatch without exposing permanent credentials.

Deploy an **Amazon EC2** instance inside the Public Subnet and:

- Attach the IAM Role.
- Configure the Security Group to allow HTTP and HTTPS traffic.
- Install **Java Development Kit (JDK) 21**.
- Deploy and run the Spring Boot application.

### Step 4: Static File Storage Configuration (Amazon S3)

Create an **Amazon S3 Bucket** to store maintenance images and technical documents uploaded by users.

The Spring Boot application uploads and retrieves files from Amazon S3 using IAM permissions, eliminating the need to store files directly on the EC2 server.

### Step 5: System Monitoring (Amazon CloudWatch)

Configure **Amazon CloudWatch** to collect logs generated by the Spring Boot application running on Amazon EC2.

CloudWatch enables the development team to:

- Monitor application logs.
- Track system performance.
- Detect runtime errors.
- Troubleshoot operational issues more efficiently.
